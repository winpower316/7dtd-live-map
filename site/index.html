SURVIVOR SIGNAL

プレイヤーを表示

合い言葉を入力すると、オンライン中のプレイヤー、探索済みエリアのトレーダー、補給物資、ドローン、車両の位置を表示します。

MAP FIELD GUIDE

この地図の使い方

地図を見るだけなら、そのままドラッグ・拡大できます。追加機能は合い言葉で開きます。

  1. 地図を見る ドラッグで移動、ホイールや＋−で拡大縮小。⌖で地図全体へ戻ります。
  2. プレイヤー機能へログイン PLAYERS LOCKED を押して合い言葉を入力すると、オンライン位置・履歴・再起動操作が開きます。
  3. プレイヤーを自動追従 ログイン後の FOLLOW から名前を選ぶと、10秒ごとの位置更新に合わせて地図が追従します。
  4. プレイヤー情報を見る PLAYER INFO で全プレイヤーのレベルと最終座標を確認できます。HP、ping、ゲームステージはオンライン時だけ表示します。
  5. トレーダー・物資・乗り物を確認 ログイン後は探索済みエリアのトレーダー、補給物資、ドローン、車両も表示します。未探索のトレーダーは探索時に自動表示されます。高速移動中は位置ずれを防ぐため、乗車中と思われる車両マーカーだけ一時的に隠れます。
  6. 次のホードを確認 右上に次回ホードまでの残り時間と予想現実時刻を表示します。起動中の平日・休日モードを自動反映します。

この案内は右下の「? 使い方」からいつでも再表示できます。

SERVER CONTROL

サーバーを再起動

5分後にゲームサーバーを再起動します。開始前なら中止できます。 確認のため RESTART と入力してください。
